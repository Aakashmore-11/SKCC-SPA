# Shekhar Kumar Coaching Classes (SKCC) Website

A modern, high-performance, and responsive website built for a coaching institute in Surat.

## 🚀 Getting Started

Follow these steps to run the project locally:

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm run dev
   ```

3. **Open in Browser**
   The application will be available at `http://localhost:5173`.

## 📂 Project Structure

- `src/components/`: Reusable UI components (Navbar, Footer, Layout, etc.)
- `src/pages/`: Individual page components (Home, About, Courses, Admission, etc.)
- `src/data/`: Centralized content and configuration (`content.js`)
- `src/index.css`: Global styles and Tailwind CSS configurations

## ✨ Key Features

- **Modern UI/UX**: Clean design with a Blue + White + Yellow theme.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
- **Interactive**: Smooth animations powered by Framer Motion.
- **Functional Form**: Admission form with real-time validation.
- **Engagement**: Floating WhatsApp button and scrolling announcement banner.

## 🛠 Tech Stack

- **Frontend**: React (Vite)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Routing**: React Router DOM
